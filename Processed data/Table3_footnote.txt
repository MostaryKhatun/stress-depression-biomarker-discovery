Reference network: GSE98793 (MDD); test network: GSE63878 (PTSD). Modules were detected in the reference network from 5,017 genes (the 5,000 most variable of 16,911 genes measured on both platforms, plus the hub genes and shared DEGs) using a signed network (soft-thresholding power 12, signed R² = 0.862), minimum module size 30, deepSplit 2 and merge cut height 0.25. Preservation was computed on the same genes with 200 permutations, so module sizes are those of the modules as detected. Zsummary > 10, strong; 2–10, moderate; < 2, not preserved. A lower median rank indicates stronger preservation independent of module size. r: correlation of the module eigengene with disease status (FDR, Benjamini–Hochberg). The grey set (510 unassigned genes) is not a module and is omitted. †Random sample of 1,000 genes used as a size-matched reference.
